Aviso de Privacidad

Sistema: Punto de Venta UV · Última actualización: 3 de octubre de 2026

1. Responsable del tratamiento de los datos

El responsable del tratamiento de los datos personales recabados en el módulo de facturación del sistema La Number One es el equipo tres.

2. Datos que se recopilan

Al solicitar una factura se capturan los siguientes datos:

  • Datos de la compra: folio de facturación, folio de venta y fecha de compra.
  • Datos fiscales: RFC, código postal, nombre o razón social, régimen fiscal y uso de CFDI.
  • Correo electrónico, únicamente si el usuario marca la opción de recibir la factura por correo.

3. Finalidad del uso de los datos

Los datos se utilizan para validar que la compra existe y puede facturarse, y para registrar la solicitud de facturación simulada asociada a esa venta. No se usan para fines publicitarios ni se venden a terceros.

4. Uso de los datos fiscales

Los datos fiscales se guardan junto con la solicitud para identificar a quién corresponde la factura simulada. En esta práctica no se envían al SAT ni se genera un CFDI con timbrado fiscal real.

5. Uso del correo electrónico

El correo se solicita solo cuando el usuario elige recibir la factura por esa vía y se guarda con la solicitud para ese fin. En la versión académica actual el sistema registra la preferencia, pero no realiza un envío real de correos.

6. Protección y confidencialidad de la información

Los datos se almacenan en la base de datos del sistema y solo se consultan para el proceso de facturación. Al tratarse de un proyecto académico, las medidas de seguridad no han sido auditadas ni certificadas, por lo que se recomienda no capturar datos reales sensibles fuera de un entorno de pruebas.

7. Tiempo y condiciones de conservación

Los datos se conservan mientras el proyecto académico esté en uso o hasta que el responsable los elimine de la base de datos.

8. Derechos del usuario sobre sus datos

El usuario puede solicitar acceso, rectificación, cancelación u oposición respecto de sus datos personales, así como retirar el consentimiento otorgado, mediante el medio de contacto indicado abajo.

9. Medio de contacto para dudas sobre privacidad

Para cualquier duda relacionada con este aviso, escribe a citlipop@gmail.com
